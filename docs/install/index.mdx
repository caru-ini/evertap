## On a laptop or in CI

Laptops and CI runners on Linux or macOS, x64 or arm64, take the CLI alone and need no Docker. On
Windows, use the CLI inside WSL.

```sh
curl -fsSL https://evertap.dev/install.sh | EVERTAP_ROLE=client sh
```
